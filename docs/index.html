No screen scraping, no prompt ever sent, no API calls of its own. justyap drives the same claude you run every day.

FAQ

Questions people search.

Is there a Wispr Flow alternative for Linux?

Yes. Wispr Flow isn't on Linux yet. If you use Claude Code on a paid Claude plan, justyap turns its built-in voice into typing for every Linux app.

Why is Claude Code /voice not available?

Voice needs Claude Code 2.1.69 or newer, signed in with a claude.ai account on a paid plan. It isn't available on the Free plan or with an API key. Run claude, then /login.

Can I use Claude Code's voice mode outside the terminal?

Not on its own: /voice types into Claude Code's prompt. justyap runs a hidden session, takes the transcript and pastes it wherever your cursor is.

How do I get voice typing on Ubuntu 24.04?

Clone the repo and run ./install.sh. It installs what it needs with apt and sets your hotkey. No speech model to download.

Does it work on Wayland?

Yes, on Wayland and X11.

Does it work on Fedora, Arch or Linux Mint?

It should. It's tested on Ubuntu 24.04 with GNOME. The install tab for your distro has the packages to install first, and if you try it, an issue on GitHub telling us how it went helps a lot.

Where does my audio go?

Where it goes when you use /voice in Claude Code: to Anthropic's speech-to-text, through Claude Code. justyap never records or stores audio.

Which languages does it support?

The ones Claude Code's voice supports. It follows Claude Code's language setting (/config in Claude Code).
